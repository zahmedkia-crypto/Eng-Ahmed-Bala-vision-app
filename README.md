# 📡 VISION GPS - دليل أكواد المساحة

## كيفية الحصول على APK مجاناً بخطوات بسيطة

---

## 🚀 الطريقة السهلة - GitHub (مجاني 100%)

### الخطوة 1: إنشاء حساب GitHub
1. افتح المتصفح واذهب إلى: **github.com**
2. اضغط **Sign up** (إنشاء حساب)
3. أدخل البريد الإلكتروني وكلمة المرور
4. اختر الخطة المجانية **Free**

### الخطوة 2: رفع المشروع
1. بعد تسجيل الدخول، اضغط **New repository** (مستودع جديد)
2. اسم المستودع: `VisionGPS`
3. اختر **Public** (عام)
4. اضغط **Create repository**
5. اضغط **uploading an existing file**
6. **اسحب جميع ملفات هذا المجلد** إلى الصفحة
7. اضغط **Commit changes**

### الخطوة 3: انتظر البناء التلقائي
1. اذهب إلى تبويب **Actions**
2. ستجد عملية بناء جارية (دائرة صفراء)
3. انتظر 3-5 دقائق حتى تتحول إلى علامة ✅ خضراء

### الخطوة 4: تنزيل APK
1. اذهب إلى **Releases** في الجانب الأيمن
2. انقر على آخر إصدار
3. **نزّل ملف app-debug.apk**

### الخطوة 5: تثبيت على الهاتف
1. انقل الملف إلى هاتفك
2. افتحه من مدير الملفات
3. إذا ظهرت رسالة "مصادر غير معروفة":
   - اذهب إلى الإعدادات > الأمان
   - فعّل **تثبيت من مصادر غير معروفة**
4. اضغط **تثبيت** ✅
